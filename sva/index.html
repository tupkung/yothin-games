1. เอานิ้วปิดวลีที่ขยายประธาน (of… / with… / in… / made by… / over…)
2. ถามว่าประธานตัวจริงเป็นเอกพจน์ (1) หรือพหูพจน์ (หลาย)
3. เอกพจน์ใช้ is / was / has / does / V-s ส่วนพหูพจน์ใช้ are / were / have / do / V
