1. สารผสมกับสารละลาย (First Principles)

1.1 สารบริสุทธิ์ vs สารผสม

จำจากบทที่แล้วได้ไหมครับ — ทุกอย่างทำจาก อนุภาค (particles)

อนุภาคข้างใน ตัวอย่าง
สารบริสุทธิ์ (pure substance) มี ชนิดเดียว น้ำกลั่น · ทองคำแท่ง · น้ำตาลทราย
สารผสม (mixture) มี ตั้งแต่ 2 ชนิด ปนกัน น้ำเกลือ · อากาศ · น้ำโคลน · ข้าวผัด

หัวใจของทั้งบทอยู่ตรงนี้: ในสารผสม ทุกตัวยังเป็นตัวเดิม เกลือในน้ำเกลือยังเค็มเหมือนเดิม · ทรายในน้ำโคลนยังเป็นทรายเหมือนเดิม ไม่มีใครกลายเป็นสารใหม่ → เลยแยกกลับออกมาได้

1.2 เนื้อเดียว vs เนื้อผสม

มองด้วยตา ตัวอย่าง
สารเนื้อเดียว (homogeneous) เห็นเป็นเนื้อเดียวกันหมด แยกส่วนไม่ออก น้ำเกลือ · น้ำเชื่อม · อากาศ
สารเนื้อผสม (heterogeneous) เห็นเป็นส่วน ๆ ชัด น้ำโคลน · น้ำมันลอยบนน้ำ · ส้มตำ

สารละลาย (solution) = สารผสมที่เป็นเนื้อเดียว มี 2 บทบาท:

  • ตัวทำละลาย (solvent) = ตัวที่ "รับ" ตัวอื่นเข้าไป
  • ตัวละลาย (solute) = ตัวที่ "เข้าไปแทรก"

วิธีบอกว่าใครเป็นตัวทำละลาย:

  • สถานะต่างกัน → ตัวที่สถานะเหมือนสารละลายคือตัวทำละลาย (น้ำเชื่อมเป็นของเหลว → น้ำเป็นตัวทำละลาย · น้ำตาลเป็นตัวละลาย)
  • สถานะเหมือนกัน → ตัวที่มีปริมาณมากกว่าคือตัวทำละลาย (แอลกอฮอล์ล้างแผล 70% → แอลกอฮอล์เป็นตัวทำละลาย)

📌 ข้อสอบ O-NET ปี 66 ข้อ 5 ถามว่า "ของแข็ง A ละลายในของเหลว B" อนุภาคหน้าตาเป็นยังไง — เฉลยทางการคือ อนุภาค A กับ B แยกเป็นตัวเดี่ยวกระจายปนกันทั่ว ไม่จับกลุ่ม ไม่จับคู่กัน = ภาพเดียวกับที่บทที่ 1 เล่าว่าเกลือ "ไปแทรกอยู่ระหว่างอนุภาคน้ำ"

1.3 กฎเหล็กของบทนี้

🔑 แยกสาร = หา "ความต่าง" 1 อย่าง แล้วใช้มันเป็นประตู

ถ้าสองตัวต่างกันเรื่องไหน เราก็ใช้เรื่องนั้นแยก ขนาดต่าง → ใช้รู · น้ำหนักต่าง → ใช้ลม · แม่เหล็กดูดได้ตัวเดียว → ใช้แม่เหล็ก ถ้าไม่ต่างกันเลยในเรื่องนั้น ประตูนั้นก็ใช้ไม่ได้ — ต่อให้เป็นวิธีที่ฟังดูเก่งแค่ไหนก็ตาม

2. ประตูแยกสาร 8 บาน (ถามความต่างก่อน แล้วค่อยเลือกประตู)

ความต่าง ประตู (วิธีแยก) English ตัวอย่าง
ชิ้นใหญ่ มองเห็น นับได้ การหยิบออก hand-picking เก็บก้อนหินออกจากข้าวสาร
ขนาดเม็ดต่างกัน การร่อน sieving ร่อนแป้งให้ก้อนใหญ่ค้างตะแกรง
เบา–หนักต่างกัน (ลมพัดได้ตัวเดียว) การฝัด winnowing ฝัดข้าวให้แกลบปลิวออก
ตัวหนึ่งเป็นสารแม่เหล็ก ใช้แม่เหล็ก magnetic separation ดูดตะปูออกจากขี้เลื่อย
ของแข็งไม่ละลายในของเหลว การกรอง filtration กรองกากกาแฟ
ของแข็งละลายอยู่ อยากได้ของแข็งคืน การระเหยแห้ง evaporation to dryness นาเกลือตากน้ำทะเล
จุดเดือดต่างกัน อยากได้ของเหลวคืน การกลั่น distillation ทำน้ำกลั่นจากน้ำประปา
ของเหลว 2 ชนิดไม่ผสมกัน กรวยแยก separating funnel แยกน้ำมันออกจากน้ำ

บานพิเศษที่ต้องรู้: ของแข็งหนักจมลงก้น → การตกตะกอน (sedimentation) แล้วค่อยรินส่วนใสออก

⭐ สารผสม 3 ตัวขึ้นไป = ใช้หลายประตูต่อกัน

เช่น ทราย + เกลือ ปนกันแห้ง ๆ:

  1. เติมน้ำคน → เกลือละลาย ทรายไม่ละลาย (สร้างความต่างขึ้นมาเอง!)
  2. กรอง → ทรายค้างบนกระดาษกรอง
  3. ระเหยแห้ง น้ำที่ผ่านกระดาษกรองลงไป → ได้เกลือคืน

เคล็ดลับ: ถ้าสองตัวไม่ต่างกันในสภาพตอนนี้ ให้ถามว่า "ถ้าใส่น้ำลงไป มันจะต่างกันไหม?"

🧪 ลองเอง (ปิดตอน 1 — ทำ 3 ข้อนี้ก่อนพัก)

ข้อ 1 ผงตะไบเหล็กหกลงไปในกระบะทราย — ใช้วิธีไหนเร็วที่สุด? (กดดูเฉลย)

ตอบ: ใช้แม่เหล็ก (magnetic separation)

ความต่างคือ เหล็กเป็นสารแม่เหล็ก ทรายไม่เป็น → ใช้ความต่างนั้นเป็นประตู ร่อนไม่ได้เพราะเม็ดเล็กพอ ๆ กัน · กรองก็ไม่มีของเหลวให้กรอง

ข้อ 2 ต้องการ "น้ำตาล" กลับคืนจากน้ำเชื่อม ใช้วิธีใด?

ตอบ: การระเหยแห้ง (evaporation to dryness)

น้ำตาลละลายอยู่ในน้ำ → กรองยังไงก็ไม่ติดกระดาษกรอง (มันเล็กระดับอนุภาค) ต้องไล่น้ำ (ตัวทำละลาย) ออกไป น้ำตาลจึงกลับมาเป็นของแข็ง

ข้อ 3 ข้าวเปลือกตากแห้งแล้ว มีเศษฟางชิ้นเบา ๆ ปนอยู่เยอะมาก — ใช้วิธีใด?

ตอบ: การฝัด (winnowing)

ความต่างคือ น้ำหนัก — ฟางเบาลมพัดปลิว ข้าวหนักตกลงกระด้ง หยิบออกก็ได้แต่ช้ามากเพราะเยอะ · ข้อสอบถาม "วิธีที่เหมาะสมที่สุด" จึงต้องเลือกวิธีที่ใช้ความต่างได้ตรงที่สุด

🎉 จบตอน 1 แล้วครับ พักได้เลย หรือถ้ายังไหวก็ไปเล่นเกมด่าน 1 ก่อนอ่านตอน 2

3. ข้อสอบจริงเรื่องแยกสาร — อ่านอังกฤษก่อน แล้วค่อยไทย

3.1 อุ่นเครื่องด้วยข้อที่น้องอ่านสบาย (Pretest บดินทรเดชา ห้อง EP ปี 68 ข้อ 70)

Four students use the following methods to separate substances: A. Separate salt solution from sand using sieving. B. Separate sand from salt solution by hand-picking. C. Separate salt solution from sand using filtration. D. Separate salt solution using evaporation. Which 2 options represent the most appropriate method for separating salt from the mixture?

  1. A and B 2) B and C 3) C and D 4) D and A

ลองคิดก่อนนะ... นี่คือข้อ "หลายประตูต่อกัน" จาก §2 เป๊ะ

ตอบ: 3) C and D — กรองทรายออกก่อน (C) แล้วระเหยน้ำเกลือให้ได้เกลือ (D) A ผิดเพราะน้ำเกลือไม่ค้างตะแกรง · B ผิดเพราะเม็ดทรายเล็กเกินจะหยิบ (บดินทรไม่มีเฉลยในคลัง — ข้อนี้พี่วิเคราะห์จากหลักการ)

3.2 ข้อสอบไทย — O-NET ป.6 ปี 67 ข้อ 6

ข้อใดใช้วิธีการที่ไม่เหมาะสมในการแยกสารผสมออกจากกัน

  1. แยกน้ำมันที่ลอยบนน้ำแกงด้วยการกรองผ่านกระดาษกรอง
  2. แยกผงเหล็กออกจากเมล็ดข้าวด้วยแม่เหล็ก
  3. แยกกากมะพร้าวออกจากน้ำกะทิด้วยการกรองกระดาษกรอง
  4. แยกเปลือกของเมล็ดถั่วลิสงกับเมล็ดถั่วลิสงคั่วด้วยการฝัด

เฉลยทางการ: 1 — น้ำมันกับน้ำเป็นของเหลวทั้งคู่ ไหลผ่านกระดาษกรองได้ทั้งคู่ → กรองไม่ออก ความต่างจริงคือ "ไม่ผสมกัน ลอยคนละชั้น" → ต้องใช้กรวยแยก หรือตักน้ำมันออก

⚠️ "ไม่เหมาะสม" = หาข้อที่ผิด · วงคำว่า "ไม่" ก่อนอ่านช้อยส์ทุกครั้ง (นิสัยเดียวกับบทที่ 1)

3.3 ข้อที่ยากที่สุดของกลุ่มนี้ — O-NET ป.6 ปี 64 ข้อ 25

สารผสมในน้ำ มีของแข็ง 4 ตัว:

สาร ขนาด (มม.) ละลายน้ำ สารแม่เหล็ก
A 1.0 ละลาย ไม่เป็น
B 0.5 ไม่ละลาย ไม่เป็น
C 1.5 ละลาย ไม่เป็น
D 2.0 ไม่ละลาย เป็น

25.2 ถ้ากรองด้วยตะแกรงรู 1 มม. สาร C และ D จะค้างอยู่บนตะแกรง — ใช่หรือไม่?

เด็กส่วนใหญ่ดูแค่คอลัมน์ขนาด: C = 1.5 มม. ใหญ่กว่ารู → "ค้าง" → ตอบ ใช่ เฉลยทางการ: ไม่ใช่ ❌

เพราะ C ละลายน้ำ — พอลงไปอยู่ในน้ำ มันไม่ใช่เม็ด 1.5 มม. อีกต่อไป มันแตกเป็นอนุภาคเล็กจิ๋วไหลผ่านรูไปกับน้ำ ค้างตะแกรงจริงมีแค่ D ตัวเดียว

🔑 คำถามที่ต้องถามก่อนดูขนาดทุกครั้ง

"ตัวนี้ละลายอยู่หรือเปล่า?" ละลายแล้ว = ขนาดในตารางไม่มีความหมาย · ไม่มีตะแกรงหรือกระดาษกรองไหนจับได้ เอาคืนได้ทางเดียวคือ ไล่น้ำออก (ระเหยแห้ง/กลั่น)

(ข้อ 25.1 ที่บอกว่า "ของแข็ง B, D + ของเหลวที่มีน้ำ A C" = ใช่ ✔ และ 25.3 กรอง → ล้าง → ตาก → แม่เหล็กดูด D ออก เหลือ B = ใช่ ✔ ตามเฉลยทางการ)

4. เคมีหรือกายภาพ — ขั้นที่ลึกกว่าบทที่ 1

บทที่ 1 ให้กฎไว้แล้ว: เกิดสารใหม่ = เคมี (chemical change) · ยังเป็นสารเดิม = กายภาพ (physical change) ปัญหาคือ ในข้อสอบเรามองไม่เห็นอนุภาค — ต้องดูจาก "สัญญาณ" แทน

4.1 สัญญาณว่าอาจเกิดสารใหม่ (clues)

สัญญาณ ตัวอย่าง
มีฟองแก๊ส ทั้งที่ไม่ได้ต้ม เบกกิ้งโซดา + น้ำส้มสายชู ฟู่
ของเหลวใส 2 ชนิดผสมกัน แล้วเกิดตะกอน ใสสองแก้ว เทรวม → ขุ่นมีผงตกลงมา
สีเปลี่ยนเป็นสีใหม่ (ไม่ใช่แค่สีของตัวที่เติมลงไป) แอปเปิลหั่นทิ้งไว้เป็นสีน้ำตาล
มีแสง/ความร้อนออกมาเอง จุดไม้ขีดไฟ
กลิ่นใหม่ นมบูดมีกลิ่นเปรี้ยว

ข้อสอบ Bordin EP ปี 67 ข้อ 73 ถามเป็นภาษาอังกฤษว่า "Which indicate that a chemical reaction has occurred? — an odor / a change in color / gas bubbles / all of these" → คำตอบคือ all of these เพราะทั้งหมดเป็น "สัญญาณ" (วิเคราะห์เอง — บดินทรไม่มีเฉลย)

4.2 แต่สัญญาณ "หลอก" ได้ — ต้องถามว่ามันมาจากไหน

เห็นอะไร ถ้ามาจาก... แบบใด
ฟอง ต้มน้ำจนเดือด (ไอน้ำ = น้ำเดิม) กายภาพ
ตะกอน ของแข็งที่ไม่ละลาย จมลงก้น (ดิน ทราย) กายภาพ
สีเปลี่ยน ละลายผงสีลงน้ำ (สีมาจากผงเดิม) กายภาพ
แสง + ความร้อน หลอดไฟ (ไส้หลอดยังเป็นโลหะเดิม) กายภาพ

A. ของแข็งสีแดงละลายได้ในของเหลว B. ของเหลว 2 ชนิดผสมกันแล้วเกิดฟองแก๊ส C. ของเหลวไม่มีสี 2 ชนิดผสมกันเกิดตะกอนสีเหลือง D. ของแข็งสีแดงผสมกับน้ำ มีบางส่วนลอยและบางส่วนตกตะกอน การเปลี่ยนแปลงใดเป็นการเปลี่ยนแปลงทางเคมี · 1. A, B 2. B, C 3. C, D 4. B, D

เฉลยทางการ: 2 (B และ C)

  • A = การละลาย → สีแดงมาจากของแข็งเดิม → กายภาพ (กับดักสี)
  • D = ของแข็งไม่ละลาย ลอยบ้างจมบ้าง → กายภาพ (กับดักตะกอน)
  • C กับ D มีคำว่า "ตะกอน" ทั้งคู่ แต่ C เกิดจากของเหลวใสสองตัว = มีสารใหม่โผล่มา · D เป็นของแข็งเดิมที่ไม่ละลาย

🧪 ลองเอง (ปิดตอน 2)

ข้อ 4 (O-NET ป.6 ปี 64 ข้อ 8 — ย่อ) ของแข็งสีขาว 4 ตัว: W ใส่น้ำมีฟองแก๊ส · X ใส่น้ำเกลือได้ของเหลวใส · Y ให้ความร้อนเหลวเป็นสีน้ำตาล · Z เผาแล้วมีแก๊สและแตกเป็นผง — มีตัวเดียวที่ไม่เกิดสารใหม่ คือตัวไหน?

ตอบ: X (เฉลยทางการ = ข้อ 2)

X แค่ละลายในน้ำเกลือ ได้ของเหลวใส ไม่มีสัญญาณอะไรเลย = กายภาพ W มีฟองโดยไม่ได้ต้ม · Y สีเปลี่ยนเป็นน้ำตาล (เหมือนน้ำตาลเคี่ยวเป็นคาราเมล) · Z เผาแล้วมีแก๊สใหม่ → เคมีทั้งสามตัว

ข้อ 5 ต้มน้ำในกาจนเดือด เห็นฟองผุดขึ้นเต็มไปหมด — เคมีหรือกายภาพ?

ตอบ: กายภาพ

ฟองคือไอน้ำ = น้ำตัวเดิมที่เปลี่ยนสถานะ (บทที่ 1: เปลี่ยนสถานะ = กายภาพเสมอ) "มีฟอง" เป็นสัญญาณเคมีเฉพาะตอนที่ไม่ได้ต้มเท่านั้น

🎉 จบตอน 2 พักได้ หรือไปเล่นเกมด่าน 1–2 ก่อนอ่านตอน 3

5. กับดักที่ข้อสอบชอบวาง (5 ตัว)

📌 กับดักในบทนี้มาจาก คลังข้อสอบจริง เพราะน้องยังไม่เคยทำชุดวัดวิทย์ พอมีผลวัดวิทย์รอบแรกแล้ว พี่จะกลับมาเปลี่ยน §5 เป็น กับดักของน้องเอง

⛔ กับดัก 1 — ของที่ละลายแล้ว กรองไม่ออก

ดูขนาดในตารางแล้วตอบว่า "ค้างตะแกรง" ทั้งที่มันละลายไปแล้ว (O-NET 64 ข้อ 25.2) → ถาม "ละลายอยู่ไหม?" ก่อนดูขนาดเสมอ

⛔ กับดัก 2 — กระดาษกรองแยกของเหลวออกจากของเหลวไม่ได้

น้ำมัน + น้ำ ไหลผ่านกระดาษกรองได้ทั้งคู่ (O-NET 67 ข้อ 6) → ของเหลวไม่ผสมกัน = กรวยแยก

⛔ กับดัก 3 — ฝัดได้เฉพาะตอน "น้ำหนักต่างกัน"

ถั่วเขียวกับลูกเกด ขนาดใกล้กัน (ร่อนไม่ได้) และหนักพอ ๆ กัน (ฝัดไม่ได้) → เหลือทางเดียวคือ หยิบออก (O-NET 66 ข้อ 6 เฉลยทางการ = หยิบออก)

⛔ กับดัก 4 — ฟอง/ตะกอน/สี ไม่ได้แปลว่าเคมีเสมอ

ถามทุกครั้งว่ามาจากไหน — มาจากต้ม/ของไม่ละลาย/ผงสีเดิม = กายภาพ (O-NET 67 ข้อ 5 ตัวเลือก A, D)

⛔ กับดัก 5 — ระเหยแห้งได้ของแข็งคืน แต่ "น้ำหายไปเลย"

อยากได้น้ำจืดจากน้ำทะเล ต้องกลั่น (เก็บไอน้ำมาควบแน่น) ไม่ใช่ระเหยแห้ง · อยากได้เกลือ ถึงใช้ระเหยแห้ง → อ่านให้ดีว่าโจทย์อยากได้ตัวไหนคืน

6. Language Bridge (ศัพท์ในบทนี้เท่านั้น)

ไทย (ตามที่โจทย์ใช้) English จุดที่ต้องระวัง
สารบริสุทธิ์ / สารผสม pure substance / mixture น้ำกลั่น = บริสุทธิ์ · น้ำแร่ = สารผสม
สารเนื้อเดียว / สารเนื้อผสม homogeneous / heterogeneous อากาศ = เนื้อเดียว
สารละลาย solution = สารผสมเนื้อเดียว
ตัวทำละลาย / ตัวละลาย solvent / solute สถานะเหมือนสารละลาย หรือปริมาณมากกว่า = solvent
การหยิบออก / การร่อน / การฝัด hand-picking / sieving / winnowing ฝัด = ใช้ลม แยกเบา–หนัก
การกรอง filtration ⚠️ "กรอง" ≠ "กระดาษกรอง" (อันหลังคืออุปกรณ์)

การกลั่น distillation ได้ของเหลวคืน

การเปลี่ยนแปลงทางเคมี / ทางกายภาพ chemical / physical change ดูสัญญาณ + ถามว่ามาจากไหน

คำสั่งโจทย์ไทยที่ต้องแปลอัตโนมัติ: "วิธีที่ไม่เหมาะสม" = which method is NOT appropriate · "เหมาะสมที่สุด" = the most appropriate · "ใช่หรือไม่ใช่" = true or false (ตอบทีละข้อย่อย)

11. ปริศนาปิดท้าย (ยากกว่าข้อสอบจริงเล็กน้อย)

โจทย์: น้องทำ ผงตะไบเหล็ก + ทราย + เกลือป่น หกปนกันในจานเดียว อยากได้ของทั้งสามอย่างกลับคืนแยกกัน ครบทุกตัว

ลำดับขั้นใดทำได้สำเร็จ? ก. ใช้แม่เหล็กดูด → เติมน้ำคนให้ทั่ว → กรอง → นำของเหลวที่ผ่านกระดาษกรองไประเหยแห้ง ข. เติมน้ำคนให้ทั่ว → นำทั้งหมดไประเหยแห้ง → ใช้แม่เหล็กดูด ค. ใช้แม่เหล็กดูด → ร่อนด้วยตะแกรงตาถี่ → เติมน้ำคน ง. เติมน้ำคนให้ทั่ว → กรอง → นำของที่ค้างบนกระดาษกรองไประเหยแห้ง

กดดูเฉลยเต็ม 4 ส่วน

1. คำตอบ: ก.

2. Step-by-Step

  1. ถามความต่างก่อน: เหล็ก = แม่เหล็ก · ทราย = ไม่ละลาย · เกลือ = ละลาย
  2. แม่เหล็ก ดูดเหล็กออกมาก่อน → เหลือทราย + เกลือ ✔ ได้เหล็กคืน
  3. ทรายกับเกลือเม็ดพอ ๆ กัน แห้ง ๆ แยกไม่ได้ → สร้างความต่างด้วยน้ำ: เกลือละลาย ทรายไม่ละลาย
  4. กรอง → ทรายค้างบนกระดาษกรอง ✔ ได้ทรายคืน
  5. น้ำเกลือที่ผ่านลงไป → ระเหยแห้ง ✔ ได้เกลือคืน

3. ตัวลวงผิดเพราะอะไร

  • ข. ระเหยแห้งทั้งหมดแล้วเกลือกลับไปปนกับทรายเหมือนเดิม — ขาดขั้นกรอง
  • ค. ทรายกับเกลือป่นเม็ดใกล้กัน ร่อนไม่ออก · และจบที่เติมน้ำ ยังไม่ได้เกลือคืน
  • ง. เอาผิดส่วนไประเหย — บนกระดาษกรองคือทราย+เหล็ก (ไม่มีเกลือ) · เกลืออยู่ในน้ำที่ไหลผ่านไปแล้ว และเหล็กก็ยังปนทราย

4. สังเกตข้อสอบ (Exam Insight) ข้อลำดับหลายขั้นวัดว่าน้อง "ตามของได้ไหมว่าหลังแต่ละขั้น อะไรอยู่ตรงไหน" · เทคนิค: วาดกล่องเล็ก ๆ ต่อขั้น เขียนว่าในกล่องมีอะไรเหลือ · ช้อยส์ที่ตก ไม่ได้ตกเพราะใช้วิธีผิดชื่อ แต่ตกเพราะลำดับผิด หรือเก็บผิดส่วน

  4. 💬 สงสัยตรงไหนถามพี่ได้เลยในแชต
