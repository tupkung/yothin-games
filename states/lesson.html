1. สสารกับความร้อน (First Principles)

1.1 สสารทำจากอะไร

ทุกอย่างรอบตัวน้อง — น้ำ อากาศ โต๊ะ ตัวน้องเอง — ทำจาก อนุภาค (particles) เล็กจิ๋วมองไม่เห็น อนุภาคพวกนี้ ขยับอยู่ตลอดเวลา ไม่เคยหยุดนิ่ง

สิ่งที่ทำให้น้ำกับไอน้ำต่างกัน ไม่ใช่ว่ามันเป็นสารคนละตัว — มันคือ H₂O เหมือนกันเป๊ะ ต่างกันแค่ อนุภาคอยู่ห่างกันแค่ไหน และขยับแรงแค่ไหน

1.2 สามสถานะ = สามระดับความห่าง

สถานะ English อนุภาค รูปร่าง ปริมาตร ตัวอย่าง
ของแข็ง solid ชิดกันแน่น สั่นอยู่กับที่ คงที่ คงที่ น้ำแข็ง เหล็ก
ของเหลว liquid ชิดกันแต่เลื่อนไถลได้ เปลี่ยนตามภาชนะ คงที่ น้ำ น้ำมัน
แก๊ส gas ห่างกันมาก วิ่งไปทั่ว เปลี่ยนตามภาชนะ เปลี่ยนตามภาชนะ อากาศ ไอน้ำ

ข้อสอบชอบถามด้วยตาราง ✓/✗ แบบนี้เลย (โพธิสาร ปี 69 ข้อ 13 ใช้ตารางนี้ตรง ๆ) วิธีอ่านเร็ว: ดูช่อง รูปร่าง ก่อน — ถ้า "คงที่" จบเลย = ของแข็ง ถ้ารูปร่างไม่คงที่ ให้ไปดู ปริมาตร — คงที่ = ของเหลว · ไม่คงที่ = แก๊ส

1.3 กฎเหล็กข้อเดียวของทั้งบท

🔑 ความร้อนคือตัวควบคุมความห่าง

เติมความร้อนเข้าไป → อนุภาคขยับแรงขึ้น → ห่างออกจากกัน → ไปทางแก๊ส ดึงความร้อนออก → อนุภาคขยับน้อยลง → ชิดเข้าหากัน → ไปทางของแข็ง

จำภาพนี้ภาพเดียว แล้วน้องจะตอบได้ทุกข้อในบทนี้:

ของแข็ง  ←──────  ของเหลว  ←──────  แก๊ส
 (ชิด)              (กลาง)          (ห่าง)

   ──────────────────────────────→  เติมความร้อน = ดูดความร้อน
   ←──────────────────────────────   ดึงความร้อนออก = คายความร้อน

ทางลัดที่ไม่ต้องจำอะไรเลย:

  • เดินไปทาง ขวา (ห่างขึ้น) = ดูดความร้อน (endothermic — absorb heat)
  • เดินไปทาง ซ้าย (ชิดขึ้น) = คายความร้อน (exothermic — release heat)

2. หกการเปลี่ยนสถานะ (จำ 1 กฎ ไม่ต้องจำ 6 ชื่อ)

การเปลี่ยนแปลง ไทย English ทิศ ดูด/คาย ตัวอย่างในชีวิตจริง
ของแข็ง → ของเหลว หลอมเหลว melting → ดูด น้ำแข็งกลายเป็นน้ำ
ของเหลว → ของแข็ง แข็งตัว freezing ← คาย น้ำในช่องแช่แข็ง
ของเหลว → แก๊ส ระเหย evaporation → ดูด ผ้าตากแดดแห้ง
ของเหลว → แก๊ส (เดือดทั่วก้อน) เดือด boiling → ดูด ต้มน้ำเดือด 100 °C
แก๊ส → ของเหลว ควบแน่น condensation ← คาย หยดน้ำข้างแก้วน้ำเย็น
ของแข็ง → แก๊ส (ข้ามของเหลว) ระเหิด sublimation → ดูด ลูกเหม็น การบูร น้ำแข็งแห้ง

ตัวที่ 7 ที่ออกน้อยแต่ควรรู้: แก๊ส → ของแข็ง = ระเหิดกลับ (deposition) → คาย · เช่น น้ำค้างแข็งเกาะใบไม้

⭐ ระเหย (evaporation) ต่างจาก เดือด (boiling) ยังไง

ทั้งคู่คือ ของเหลว → แก๊ส เหมือนกัน แต่:

ระเหย เดือด
เกิดที่ไหน ผิวหน้าเท่านั้น ทั่วทั้งก้อน (เห็นฟอง)
อุณหภูมิ อุณหภูมิไหนก็ได้ ต้องถึง จุดเดือด
เร็วแค่ไหน ช้า เร็ว

ผ้าตากแดดแห้ง = ระเหย (ไม่ได้เดือด) · น้ำในกาส่งเสียงปุด ๆ มีฟอง = เดือด

🧪 ลองเอง (ปิดตอน 1 — ทำ 3 ข้อนี้ก่อนพัก)

ข้อ 1 เอาลูกเหม็นวางไว้ในตู้เสื้อผ้า 1 เดือน พบว่าเล็กลงเรื่อย ๆ จนหมด — นี่คือการเปลี่ยนสถานะแบบใด ดูดหรือคายความร้อน? (กดดูเฉลย)

ตอบ: ระเหิด (sublimation) · ดูดความร้อน

ลูกเหม็นเป็น ของแข็ง แล้วหายไปเป็น แก๊ส ในอากาศ (เราได้กลิ่น = มีแก๊สลอยมา) โดยไม่เคยเห็นเป็นของเหลวเลย → ข้ามขั้นของเหลว = ระเหิด ไปทางห่างขึ้น (ของแข็ง → แก๊ส) = ดูดความร้อน ตามกฎเหล็ก

ข้อ 2 เอาแก้วน้ำเย็นวางบนโต๊ะ สักพักมีหยดน้ำเกาะรอบนอกแก้ว — หยดน้ำนั้นมาจากไหน?

ตอบ: มาจาก "ไอน้ำในอากาศ" ที่ควบแน่น (condensation) · คายความร้อน

ไม่ได้ซึมออกมาจากในแก้วนะครับ! อากาศรอบตัวเรามี ไอน้ำ (แก๊ส) อยู่แล้ว พอไอน้ำเจอผิวแก้วที่เย็น มันจะ เสียความร้อน → อนุภาคชิดกัน → กลายเป็นของเหลวเกาะข้างแก้ว ไปทางชิดขึ้น (แก๊ส → ของเหลว) = คายความร้อน

ข้อนี้ออกสอบจริงในสามเสน ปี 69 ข้อ 45 (เป็นหม้อใส่น้ำแข็งแทนแก้ว) — ตัวลวงที่เด็กเลือกเยอะคือ "น้ำซึมออกมาจากในหม้อ"

ข้อ 3 เรียงลำดับ: น้ำแข็ง → น้ำ → ไอน้ำ ใช้ชื่อการเปลี่ยนสถานะอะไร ตามลำดับ? และดูดหรือคาย?

ตอบ: หลอมเหลว (melting) → ระเหย/เดือด (evaporation/boiling) · ดูดความร้อนทั้งสองขั้น

เพราะเดินไปทางขวา (ชิด → ห่าง) ทั้งสองขั้น = ดูดความร้อน ทั้งคู่ คำว่า "ตามลำดับ" ในโจทย์ไทย = respectively — ต้องตอบเรียงให้ตรงคู่กับที่โจทย์ถาม

🎉 จบตอน 1 แล้วครับ พักได้เลย หรือถ้ายังไหวก็ไปเล่นเกมด่าน 1 ก่อนอ่านตอน 2

3. กับดักใหญ่ที่สุดของหัวข้อนี้ — "หายไป" ไม่ได้แปลว่าเปลี่ยนสถานะ

ตอนนี้ถึงจุดที่สำคัญที่สุดของทั้งบทแล้วครับ อ่านช้า ๆ นะ

3.1 เริ่มจากข้อสอบที่น้องอ่านสบายก่อน (ภาษาอังกฤษ)

ข้อนี้มาจาก Pretest บดินทรเดชา ห้อง EP ปี 68 ข้อ 69 — เป็นภาษาอังกฤษ:

Observe the following. A. Leaving pieces of camphor in a room causes them to shrink over time. B. Adding salt to water causes it to dissolve, leaving the water clear and colorless. C. Spraying alcohol on the skin causes it to evaporate. D. Adding ice to water causes it to melt, resulting in clear and colorless water. Which options show changes in states of matter?

  1. A B C 2) A B D 3) B C D 4) A C D

ลองคิดก่อนนะครับ แล้วค่อยอ่านต่อ

3.2 ข้อเดียวกันเป๊ะ ในภาษาไทย (O-NET ป.6 ปี 65 ข้อ 5)

จากการสังเกตต่อไปนี้ A การวางเกล็ดการบูรไว้ เกล็ดการบูรมีขนาดเล็กลง B การใส่เกลือลงไปในน้ำ เม็ดเกลือหายไป ได้ของเหลวใส ไม่มีสี C การฉีดสเปรย์แอลกอฮอล์บนผิวหนัง แล้วแอลกอฮอล์หายไป D การใส่น้ำแข็งลงไปในแก้วที่มีน้ำ น้ำแข็งหายไป ได้ของเหลวใส ไม่มีสี ข้อใดเป็นการเปลี่ยนสถานะ

  1. A B C 2. A B D 3. B C D 4. A C D

เฉลยทั้งสองข้อ: ตัวเลือก 4 = A C D (เฉลยทางการของ สทศ. ยืนยัน)

3.3 ทำไม B ไม่ใช่ — และนี่คือกับดักภาษาไทยของเด็ก EP

ข้อ เกิดอะไร เปลี่ยนสถานะ?
A การบูร: ของแข็ง → แก๊ส = ระเหิด ✅ ใช่
B เกลือ + น้ำ = การละลาย (dissolving) ❌ ไม่ใช่
C แอลกอฮอล์: ของเหลว → แก๊ส = ระเหย ✅ ใช่
D น้ำแข็ง: ของแข็ง → ของเหลว = หลอมเหลว ✅ ใช่

B ไม่ใช่เพราะ: เกลือ ไม่ได้เปลี่ยนสถานะ เลย — เกลือยังเป็นของแข็งอยู่ แค่แตกตัวกระจายไปแทรกอยู่ระหว่างอนุภาคน้ำ จนเล็กเกินกว่าจะมองเห็น พิสูจน์ง่าย ๆ : เอาน้ำเกลือไปตากแดดให้น้ำระเหยไป → เกลือกลับมาเป็นเม็ดของแข็งเหมือนเดิม เพราะมันไม่เคยหายไปจริง

⚠️ สังเกตให้ดี — ข้อสอบเขียน B กับ D ด้วยคำ "เหมือนกันเป๊ะ" โดยตั้งใจ

กลับไปอ่านสองข้อนี้อีกรอบ:

ข้อ โจทย์เขียนว่า คำตอบจริง
B เม็ดเกลือหายไป ได้ของเหลวใส ไม่มีสี dissolve ❌ ไม่ใช่การเปลี่ยนสถานะ
D น้ำแข็งหายไป ได้ของเหลวใส ไม่มีสี melt ✅ เป็นการเปลี่ยนสถานะ

เห็นไหมครับว่า คำบรรยายเหมือนกันทุกคำ แต่คำตอบตรงกันข้าม → แปลว่า คำว่า "หายไป" หรือ "ใสไม่มีสี" ใช้ตัดสินไม่ได้เลย ข้อสอบจงใจเขียนให้เหมือนกันเพื่อดักคนที่จับแค่คำ

🔑 คำถามที่ใช้ตัดสินได้จริง

"ของแข็งนั้นกลายเป็นของเหลว ของตัวมันเอง หรือไป แอบแทรกอยู่ในของเหลวอื่น?"

  • กลายเป็นของเหลวของตัวเอง → melt · น้ำแข็ง (H₂O แข็ง) กลายเป็นน้ำ (H₂O เหลว) — ของเดิมตัวเดียวกัน เปลี่ยนแค่สถานะ
  • ไปแทรกในของเหลวอื่นที่มีอยู่ก่อน → dissolve · เกลือไม่ได้กลายเป็น "เกลือเหลว" นะ — มันไปแทรกอยู่ในน้ำ เกลือยังเป็นเกลือ น้ำยังเป็นน้ำ แค่ปนกันจนมองไม่เห็น

เช็กซ้ำได้อีกชั้น: ถ้าไล่น้ำออกไปแล้วได้ของคืนมาสองอย่างแยกกัน (เกลือ + น้ำ) = dissolve ถ้าได้ของเดิมอย่างเดียวในสถานะอื่น (น้ำแข็ง ↔︎ น้ำ) = melt

⛔ กับดักภาษาไทยที่ดักเด็ก EP เป็นพิเศษ

ภาษาไทยใช้คำว่า "ละลาย" สำหรับ สองเรื่องที่ต่างกันสิ้นเชิง แต่ภาษาอังกฤษแยกกันชัดเจน:

ภาษาไทยพูดว่า ภาษาอังกฤษ คืออะไร เปลี่ยนสถานะ?
"น้ำแข็งละลาย" melt ของแข็ง → ของเหลว ✅ ใช่
"เกลือละลายน้ำ" dissolve กระจายตัวในตัวทำละลาย ❌ ไม่ใช่

น้องเรียน EP มา น้องแยก melt กับ dissolve ออกอยู่แล้วตามธรรมชาติ แต่พอโจทย์เป็นภาษาไทย มันใช้คำเดียวกัน — นี่คือจุดที่เด็ก EP เสียคะแนนฟรี วิธีแก้: เจอคำว่า "ละลาย" ในโจทย์ไทย ให้หยุด 1 วินาที ถามตัวเองว่า "อันนี้ melt หรือ dissolve?" แล้วค่อยตอบ

4. ผันกลับได้ไหม + เคมีหรือกายภาพ

4.1 การเปลี่ยนสถานะทุกตัว = ทางกายภาพ + ผันกลับได้

คำถาม คำตอบสำหรับ "การเปลี่ยนสถานะ"
เกิดสารใหม่ไหม ไม่เกิด — น้ำแข็ง/น้ำ/ไอน้ำ คือ H₂O เหมือนกันหมด
เป็นการเปลี่ยนแปลงแบบใด ทางกายภาพ (physical change)
ผันกลับได้ไหม ได้ (reversible) — เติม/ดึงความร้อนกลับ ก็กลับสถานะเดิม

4.2 ถ้า "เกิดสารใหม่" = ทางเคมี (มักผันกลับไม่ได้)

ตัวอย่าง เกิดอะไร แบบใด
เทียนไขหลอมเหลว ของแข็ง → ของเหลว สารเดิม กายภาพ ผันกลับได้
เทียนไขติดไฟ เกิดควันดำ + แก๊ส ได้สารใหม่ เคมี ผันกลับไม่ได้
น้ำแข็งละลาย สารเดิม กายภาพ
เหล็กเป็นสนิม / กระดาษไหม้ / ไข่ทอดสุก ได้สารใหม่ เคมี

ทางลัดตัดช้อยส์: ถามตัวเองแค่คำถามเดียว — "ได้ของใหม่ที่เอากลับเป็นของเดิมไม่ได้ไหม?" ได้ของใหม่ = เคมี · ยังเป็นของเดิมแค่เปลี่ยนหน้าตา = กายภาพ

🧪 ลองเอง (ปิดตอน 2)

ข้อ 4 (สามเสน ปี 69 ข้อ 47 — ดัดแปลง) ตารางนี้บอกอะไร? "เทียนไข: ได้ความร้อน → ของแข็งเป็นของเหลว · เสียความร้อน → กลับเป็นของแข็ง" และ "น้ำ: ได้ความร้อน → เป็นแก๊ส · เสียความร้อน → เกิดหยดน้ำ"

ตอบ: น้ำเกิดการควบแน่น (condensation) เมื่อสูญเสียความร้อน

  • เทียนไข: ของแข็ง ↔︎ ของเหลว = หลอมเหลว/แข็งตัว (ไม่ใช่ระเหิด! ระเหิดต้องข้ามไปเป็นแก๊สเลย)
  • น้ำ: แก๊ส → หยดน้ำ = ควบแน่น ✔
  • ทั้งตารางนี้ ผันกลับได้ทุกตัว → เป็นการเปลี่ยนแปลงทางกายภาพ ไม่มีสารใหม่

(หมายเหตุ: ชุดสามเสน 69 ไม่มีเฉลยทางการในคลัง — เฉลยนี้พี่วิเคราะห์จากหลักวิทยาศาสตร์ ถ้าน้องคิดว่าข้อไหนน่าสงสัย บอกพี่ได้เลย)

ข้อ 5 จุดเทียนแล้วไส้เทียนหายไป กลายเป็นควันดำและแก๊สลอยขึ้น — เคมีหรือกายภาพ เพราะอะไร?

ตอบ: ทางเคมี เพราะเกิดสารใหม่

ควันดำ (เขม่า/คาร์บอน) และแก๊สที่ลอยขึ้น ไม่ใช่เทียนไขอีกแล้ว — เป็นสารใหม่ที่เกิดจากการเผาไหม้ และเราเอาควันกลับมาปั้นเป็นเทียนไม่ได้ → ผันกลับไม่ได้

⚠️ ระวังตัวลวง: "เป็นทางเคมี เพราะมีการเปลี่ยนสถานะ" — ผิด! การเปลี่ยนสถานะคือกายภาพเสมอ เหตุผลที่ทำให้เป็นเคมีคือ เกิดสารใหม่ เท่านั้น

🎉 จบตอน 2 พักได้ หรือไปเล่นเกมด่าน 1–2 ก่อนอ่านตอน 3

5. กับดักที่ข้อสอบชอบวาง (5 ตัว)

📌 หมายเหตุถึงตัวเอง (และถึงพี่): กับดักในบทนี้ยังมาจาก คลังข้อสอบจริง ไม่ใช่จากความผิดพลาดของน้องเอง เพราะน้องยังไม่เคยทำชุดวิทย์เลย พอทำชุดวิทย์รอบแรกแล้ว พี่จะกลับมาแก้ §5 ให้เป็น กับดักของน้องเอง เหมือนบทร้อยละ

⛔ กับดัก 1 — คำว่า "หายไป / ใสไม่มีสี" ตัดสินอะไรไม่ได้เลย

ข้อสอบเขียนคำนี้ทั้งในข้อที่เป็นการเปลี่ยนสถานะและข้อที่ไม่ใช่ (B กับ D ใน §3.3 ใช้คำเหมือนกันเป๊ะ) → ห้ามตัดสินจากคำบรรยาย · ให้ถามคำถามจริงว่า "กลายเป็นของเหลวของตัวเอง (melt) หรือแทรกอยู่ในของเหลวอื่น (dissolve)?"

⛔ กับดัก 2 — ควันขาวจากน้ำแข็งแห้ง ไม่ใช่แก๊ส CO₂

น้ำแข็งแห้ง (dry ice) ระเหิดเป็น CO₂ ซึ่งมองไม่เห็น — ควันขาวที่เห็นคือ ไอน้ำในอากาศที่ควบแน่น เพราะโดนความเย็นจัด (สามเสน ปี 69 ข้อ 49 · ตัวลวงอันดับ 1 คือ "CO₂ ที่ระเหิดออกมา")

⛔ กับดัก 3 — หยดน้ำข้างภาชนะเย็น มาจากอากาศ ไม่ได้ซึมออกมา

ถ้าซึมออกมาได้จริง ภาชนะก็รั่ว — น้ำนั้นมาจาก ไอน้ำในอากาศควบแน่น (สามเสน ปี 69 ข้อ 45)

⛔ กับดัก 4 — ระเหย ≠ เดือด

ผ้าแห้งกลางแดดคือ ระเหย ไม่ใช่เดือด · เดือดต้องมีฟองทั่วทั้งก้อนและถึงจุดเดือด (§2)

⛔ กับดัก 5 — "เปลี่ยนสถานะ" ไม่เคยเป็นการเปลี่ยนแปลงทางเคมี

ถ้าช้อยส์บอกว่า "เป็นเคมีเพราะเปลี่ยนสถานะ" → ตัดทิ้งได้ทันที ไม่ต้องอ่านต่อ

7. Exam Insight — ข้อสอบออกหัวข้อนี้ในรูปไหน

หัวข้อนี้อยู่ในถัง B5 ของ blueprint (สสาร 21% อันดับ 1) ออกซ้ำ 4 รูปแบบนี้:

9. ทางลัดคิดในหัว (ใช้ตอนทำข้อสอบจริง)

  1. เจอชื่อการเปลี่ยนสถานะ ไม่ต้องท่องว่าดูดหรือคาย → วาดลูกศรในหัว: ไปทางแก๊ส = ดูด · ไปทางของแข็ง = คาย
  2. เจอตาราง ✓/✗ → อ่านช่องรูปร่างก่อนเสมอ ตัดได้ครึ่งหนึ่งทันที
  3. เจอคำว่า "ละลาย" หรือ "หายไป" → หยุด 1 วิ ถาม: กลายเป็นของเหลวของตัวเอง (melt) หรือแทรกอยู่ในของเหลวอื่น (dissolve)? · อย่าตัดสินจากคำว่า "ใสไม่มีสี" — ใช้ไม่ได้ทั้งสองฝั่ง
  4. เจอคำว่า "เกิดสารใหม่" หรือ "ผันกลับไม่ได้" → นั่นคือคำใบ้ว่าตอบ เคมี
  5. เจอช้อยส์ "เป็นเคมีเพราะเปลี่ยนสถานะ" → ตัดทิ้งทันที ไม่ต้องคิด
  6. เจอ "ข้อใดไม่ถูกต้อง" → วงคำว่า "ไม่" ก่อนอ่านช้อยส์ (นิสัยนี้ช่วยได้ทุกวิชา)

11. ปริศนาปิดท้าย (ยากกว่าข้อสอบจริงเล็กน้อย)

โจทย์: เอาแก้ว 2 ใบมาวางข้างกัน แก้ว A ใส่น้ำเกลือเข้มข้น · แก้ว B ใส่น้ำเปล่า ปริมาณเท่ากัน วางทิ้งไว้กลางแดด 3 วัน พบว่า ทั้งสองแก้วน้ำลดลง แต่ แก้ว A มีผลึกสีขาวเกาะที่ก้นแก้ว ส่วนแก้ว B ไม่มีอะไรเหลือเลย

ข้อใดอธิบายได้ถูกต้องที่สุด? ก. แก้ว A เกิดการเปลี่ยนแปลงทางเคมี เพราะเกิดผลึกสีขาวซึ่งเป็นสารใหม่ ข. แก้ว A น้ำเกิดการระเหย ส่วนเกลือไม่ระเหย จึงเหลือเป็นผลึกอยู่ก้นแก้ว ค. แก้ว A เกลือเกิดการระเหิดช้ากว่าน้ำ จึงยังเหลืออยู่ ง. ทั้งสองแก้วน้ำเกิดการเดือด เพราะโดนความร้อนจากแดด

กดดูเฉลยเต็ม 4 ส่วน

1. คำตอบ: ข.

2. Step-by-Step

  1. แดดให้ความร้อน → น้ำที่ผิวหน้า ระเหย (evaporation) กลายเป็นไอน้ำลอยไป — เกิดทั้งสองแก้ว
  2. แก้ว B มีแต่น้ำ → น้ำระเหยหมด ก็ไม่เหลืออะไร ✔
  3. แก้ว A มีเกลือ ละลาย (dissolved) อยู่ในน้ำ — เกลือ ไม่ระเหย เพราะต้องใช้ความร้อนสูงมาก
  4. พอน้ำ (ตัวทำละลาย/solvent) ลดลง เกลือที่เหลือเลยตกผลึกกลับมาเป็นของแข็งที่ก้นแก้ว
  5. นี่คือวิธีแยกสารที่เรียกว่า การระเหยแห้ง (evaporation to dryness) — และพิสูจน์ว่าการละลายไม่ใช่การเปลี่ยนสถานะ เพราะเกลือกลับมาได้เหมือนเดิม

3. ตัวลวงผิดเพราะอะไร

  • ก. ผลึกขาวคือ เกลือตัวเดิม ไม่ใช่สารใหม่ → ไม่ใช่เคมี · (กับดัก §5 ตัวที่ 5: เห็นของ "โผล่มา" แล้วรีบสรุปว่าเกิดสารใหม่)
  • ค. ระเหิด = ของแข็ง → แก๊ส โดยตรง แต่เกลือในแก้วอยู่ในรูปละลายในน้ำ และเกลือก็ไม่ได้หายไปเป็นแก๊สเลย → ใช้ชื่อผิดกระบวนการ
  • ง. เดือด ต้องถึงจุดเดือดและมีฟองทั่วทั้งก้อน แดดธรรมดาทำไม่ถึง → นี่คือ ระเหย (กับดัก §5 ตัวที่ 4)

4. สังเกตข้อสอบ (Exam Insight) ข้อแบบนี้รวม 3 หัวข้อไว้ในข้อเดียว: การเปลี่ยนสถานะ + การละลาย + การแยกสาร ซึ่งเป็นลายเซ็นของข้อยากในถัง B5 สัญญาณสังเกต: ถ้าโจทย์ให้ เปรียบเทียบ 2 อย่างที่ต่างกันแค่จุดเดียว (ที่นี่คือ "มีเกลือ vs ไม่มีเกลือ") แสดงว่าโจทย์กำลังวัดว่าน้องรู้ไหมว่า ตัวที่ต่างกันนั้นทำหน้าที่อะไร — ให้โฟกัสที่ตัวแปรนั้นตัวเดียว

12. ทำอะไรต่อ

  1. ✅ อ่านครบ 3 ตอนแล้ว → เล่น เกมด่านกับดัก (§10.1 ด่าน 3) หรือ เกมกระดาษ (§10.2)
  2. 📝 ยังไม่มีชุดวัดผลวิทย์ — พี่จะทำ examinations/science/01-states-of-matter/ ให้ หลังจากน้องอ่านบทนี้จบ เพื่อให้ตัวเลขวัดได้จริง
  3. 🔭 บทวิทย์ถัดไปตามแผน: การละลาย + การแยกสาร + สมบัติวัสดุ (สัปดาห์ 2) — ต่อจากบทนี้พอดี เพราะ §3 ปูเรื่องการละลายไว้แล้ว
  4. 💬 สงสัยตรงไหนถามพี่ได้เลยในแชต ไม่ต้องรอให้ครบ ๆ
